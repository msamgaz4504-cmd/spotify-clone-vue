# Soundwave — lecteur musical en Vue.js

Clone visuel de Spotify réalisé avec Vue 3, Vite et Tailwind CSS. Il reprend les écrans et les fonctions du projet fourni : accueil, recherche, lecture de prévisualisations, favoris, playlists, file d'attente, volume, lecture aléatoire et répétition.

Les titres, pochettes et extraits de 30 secondes proviennent de l'API de recherche iTunes. Une connexion Internet est nécessaire pour les charger.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir l'adresse locale affichée par Vite.

## Compiler

```bash
npm run build
```

Le dossier `dist/` est généré par la compilation et n'est pas à envoyer sur GitHub. Les favoris et les playlists sont conservés dans le stockage local du navigateur.
